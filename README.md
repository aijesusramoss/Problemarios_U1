ParserState.cs Es el código donde se definen los diferentes estados de nuestra Step Machine<br>
Program.cs Es el programa donde mandamos diferentes bytes a nuestra maquina para que sean procesados<br>
TelemetryFrame.cs Contiene la parte del código que se encarga de mostrar la información al usuario<br>
TelemetryParser.cs Contiene todas las funciones de procesamiento de bytes y las tranciciones estre estados<br>
TelemetryStreamParser.csproj es un archivo que crea el proyecto y comunica los archivos entre ellos<br>
